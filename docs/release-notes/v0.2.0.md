**Lightcord 0.2.0 is an alpha pre-release.** Expect rough edges, and please report problems in
[Issues](https://github.com/walmerdelarosa/Lightcord/issues), attaching `lightcord.log` when relevant
(*Settings → Advanced → Open log folder*).

> [!WARNING]
> Lightcord is an unofficial client, not affiliated with Discord Inc. Discord's Terms of Service do not allow
> third-party clients for user accounts: logging in with a **user token** may get your account restricted or
> suspended. **Bot tokens** are fully supported by the Discord API.

## Highlights

- 🎙️ **Voice chat** in server voice channels with Discord's mandatory **DAVE end-to-end encryption**
  (via Discord's libdave), Opus audio, mute/deafen, members of each voice channel and speaking indicators.
- 🔇 **Noise suppression** (RNNoise) on everything you send in a call, with adjustable strength, a voice gate and a
  live microphone test.
- 💬 **Text chat** in servers and DMs, with live updates, Discord Markdown and a permission-aware channel list.
- 🖥️ **Screen and window capture** with a live local preview (streaming to others is planned for 0.3).
- 🎨 New Lightcord identity: logo, icons, Night and Day themes.
- 🔑 Token stored in the Windows Credential Manager.

## Install

1. Download `Lightcord-0.2.0-windows-x64.zip` below and unzip it anywhere.
2. Run `Lightcord.exe`. No installer or administrator rights are needed.
3. If SmartScreen says "Windows protected your PC", choose **More info → Run anyway** (the build is not code-signed yet).

Requirements: Windows 10 or 11, 64-bit. The package is about 33 MB unzipped.

To verify the download, compare the output of `Get-FileHash Lightcord-0.2.0-windows-x64.zip` (PowerShell)
with the `.sha256` file.

## Known limitations

- Voice has passed offline tests (including a full DAVE handshake between two simulated clients) but has had
  little testing in real calls yet.
- Calls in DMs and group DMs, push-to-talk, per-user volume and DAVE verification codes are not available yet.
- Screen sharing is a local preview only; Go Live is planned for 0.3.
- No file uploads, reactions, threads or notifications yet. See the [roadmap](https://github.com/walmerdelarosa/Lightcord/blob/main/docs/ROADMAP.md).
